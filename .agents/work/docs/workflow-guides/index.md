# Workflow guides

Status: completed
Category: docs
Updated: 2026-08-29

## Why

dot-agents explains its workflow concisely, but users need practical examples for starting uncertain work, continuing durable work, and finishing without losing reusable outcomes. The site should provide that guidance without turning the landing page or documentation into a cognitively heavy framework.

## Summary

Implemented a calm local docs hub and three concise Markdown-backed guides without adding a docs framework or navigation chrome. High-mode prototypes and focused Oracle review shaped the final non-linear entry points; repository tests, the static build, link checks, multi-width browser checks, accessibility audits, keyboard interaction, and the final portal all passed.
